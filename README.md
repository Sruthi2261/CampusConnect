# CampusConnect

CampusConnect is a student-focused campus platform designed to help students discover college events, clubs, announcements, and campus resources.

## Features

- Browse upcoming campus events
- Explore student clubs
- View campus announcements
- Access campus resources
- Search campus information
- Add new events
- Store events using browser local storage
- Responsive and user-friendly interface

## Technologies

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Project Status

CampusConnect is currently being developed as a frontend web application.

Future versions will include:

- React.js frontend
- Node.js and Express.js backend
- MongoDB database
- User authentication
- Persistent event and announcement management
- Student and administrator roles
